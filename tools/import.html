LG-Datenimport

Holt Kosten und P1-Belohnungen aller Legendären Bauwerke aus dem Forge-of-Empires-Wiki (Fandom), prüft sie gegen die Formeln und erzeugt die Datendatei für den Förderrechner.

Werkzeug, keine Seite. Es gehört nicht zur ausgelieferten Website — netlify.toml beantwortet /tools/* mit 404. Lokal läuft es über npm run serve unter /tools/import.html. Das erzeugte JSON wird mit node tools/build-data.js lg-daten.json in data.js überführt.

Import

Bereit.
Seitenliste bearbeiten

Eine Zeile pro LG: Wiki-Seitentitel | deutscher Name | Zeitalter. Wenn eine Seite nicht gefunden wird, hier den Titel korrigieren.

Ergebnis

P1: echt aus dem Wiki, geschätzt per Formel, prüfen = Wiki-Wert widerspricht den Regeln. Tippe ein LG an für Details. LGs desselben Zeitalters teilen sich ihre P1-Werte.

Datenquelle: forgeofempires.fandom.com, Inhalte unter CC BY-SA. Kosten: aufgerundet A × 1,025^Stufe. P2–P5: jeweils Vorgänger ÷ n, auf 5 gerundet.
